## 基线

- 游戏：Steam 16.0.2.0，Sunbreak；运行时应显示 `mhrise / TDB 71`。
- REFramework：记录版本、Tag、Commit、日志加载行。
- 任务：单人普通大师等级轰龙；记录任务 ID 和场地。
- 安装包 SHA-256 与实际安装目录文件 SHA-256 一致。

## 专用训练任务

- QuestLoader 菜单识别 Quest ID `200032001`，且没有 Missing Spawn 或 ID 冲突。
- 集会所大师等级 4★任务列表最后显示 `[陪练] 轰龙·塔之秘境`，只出现一头普通轰龙。
- 首次只验证进入、出生、寻路、返回任务和正常退出；保持 `diagnostic_safe_mode=true`，不用 F6/F7/F8。
- 连续进入和退出 5 次无崩溃、黑屏、无限加载或任务列表污染后，才能把任务状态从 candidate 改为 verified。
- 任务结算的金钱、点数和 HRP 增量为 0；不得生成或写入怪异调查数据。

## 动作解析

- 连续记录至少 100 次 Action 转换，人工视频逐次对照漏报与重复报。
- 分别覆盖普通、怒气、近距、中距、远距。
- 读取器候选发生切换时确认当前 Action 没有跳成恒定状态或旧动作。
- 固定派生逐个验证；条件/随机派生不得显示为 fixed。

## 原地重置

- F7 只允许启动原生任务重置的只读跟踪，不得直接写回猎人或怪物 Transform。
- 从游戏菜单正常执行一次“重置任务”，确认跟踪文件包含 Reset/Return/Load 方法顺序及任务上下文变化。
- 验证怪物生命保护不会触发任务完成或永久修改任务数据。

## 时间控制

- F6 按下、持续、释放、再次按下均只发生一次语义切换。
- 任务结束、猫车、暂停、打开 REFramework、联机检测、脚本重载后均为 1.0x。
- 在 0.05x、0.25x、0.5x、1.0x 验证声音、输入和物理行为，记录异常。

## UI 与输入

- 1280×720、1920×1080、2560×1440、3440×1440；窗口/全屏各测一次。
- 中英文混排不可读时仍能看到 ASCII 诊断、Action ID 和操作键。
- Overlay 不遮挡准星/核心 HUD；长招式名和候选不覆盖面板。
- 键盘 F6/F7/F8 与游戏及常用 Mod 不冲突；控制器尚未支持时不得显示控制器提示。

## 性能与稳定性

- 对比关闭/开启 Mod 的平均帧时间；记录钩子开销，不以主观 FPS 代替。
- 同一进程完成 20 次任务进入/退出或脚本重载，记录 Lua 内存预热后趋势、历史数量和日志错误。
- 出现崩溃时保存完整 `re2_framework_log.txt` 和 dump，先区分现有 Mod 冲突与本 Mod 故障。

## 强制出招解锁门禁

只有全部满足才进入下一阶段：

1. Action ID 与招式映射已人工复核。
2. 安全动作请求方法、参数和调用线程已由 Object Explorer/行为树证据确认。
3. 进入条件、退出条件、空闲门和失败恢复已定义。
4. 每个场景循环 20 次无冻结、T-Pose、残留碰撞或任务状态污染。
