# 可接手的共建任务

欢迎带着 AI 共同完成。先搜索现有 Issue/PR；任务认领可在 Issue 中说明，维护者不承诺即时回复。各项独立提交，未验证能力继续保持锁定。

| 优先级 / 任务 | 所需环境 | 完成条件 |
|---|---|---|
| P0：子弹时间恢复验收 | 对应游戏与 REFramework | 从慢速进入菜单、退出任务、重载脚本，分别验证恢复 1×；记录提交、运行时、步骤与结果。失败时先修复再复验，不由已有切换测试推断恢复成功 |
| P0：新版本发布门禁 | 干净 REFramework + RiseQuestLoader | 候选包从明确提交生成；安装→加载版本→训练冒烟→退出→卸载；保留用户配置、其他 Mod 与回滚证据，通过后才讨论玩家安装 Release |
| P1：冰牙龙只读菜单 | 对应游戏环境 | 验证自动选包、两个顶层派生入口、无重复中间节点、无次数/开始操作，窄窗口中文无溢出；研究门禁和 F7 重开保持有效 |
| P1：冰牙龙首个高价值起手 | 有限运行时研究能力 | 优先全力尾击 35→5005→5002；区分静态顺序与实际起手条件，覆盖必要状态并证明退出/恢复；未满足证据前只观察，不开放强制入口 |
| P1：更多屏幕布局 | 不同分辨率/缩放的游戏环境 | 简洁与详细 HUD 分别检查文字、溢出、拖动和配置恢复；报告实际尺寸，修复共用 View 而非逐怪另写 UI |
| P2：资料与证据整理 | 仅离线即可 | 核查历史文档与源码差异、来源和相对链接；保留历史语境，将当前信息汇总到交接页，不以文案改动升级能力 |
| P2：手柄绑定与冲突检测 | 对应手柄和游戏 | 解析真实绑定并建立已证实的跨枚举映射；未知组合保持不可用，分别验证短按/长按/焦点与键鼠共存 |

太刀技能成功语义和更多武器属于可选扩展，不阻塞基础陪练。不要只为增加数量批量暴露内部 Action。

每项交付请使用 PR 模板，区分：离线通过、包通过、安装匹配、运行时加载、真实行为、远端发布。没有游戏也可以贡献，明确写“未做实机验收”即可。
