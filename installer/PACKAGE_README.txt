怪物猎人崛起：怪物陪练 Mod

依赖：
1. Steam《怪物猎人崛起：曙光》16.0.2.0
2. REFramework（mhrise / TDB 71）
3. RiseQuestLoader

安装：
1. 备份存档，并确保游戏已经完全退出。
2. 解压整个安装包，不要只打开 ZIP 内的脚本。
3. 双击 INSTALL.cmd；需要写入 Program Files 时接受 UAC。
4. 看到“安装并校验完成”后再启动游戏。

卸载或回滚：
1. 完全退出游戏。
2. 在同一个已解压安装包中双击 UNINSTALL.cmd。
3. 卸载器只处理安装收据列出的文件；用户配置、校准、日志和其他 Mod 会保留。

仅限单人使用。不要用于联机、正式奖励任务或怪异调查。
